# WP-00 — Scaffold monorepo  (owner: @scaffolder · implemented by Claude, ADR-012)

## Goal
A walking-skeleton monorepo that installs, typechecks, lints and tests green, with the Expo app booting to an OpenFreeMap map and a pipeline CLI stub.

## Context
CoffeeLog plan: vault `Coding/CoffeeLog/` (02 Architecture § Repo layout, § Pipeline CLI; 03 UX-UI § Design tokens). Stack: Expo SDK 57 + Expo Router (routes in `apps/mobile/src/app`), `@maplibre/maplibre-react-native` 11.x (`Map`, `Camera initialViewState`), npm workspaces, TypeScript ~6.0, Vitest for shared/pipeline, jest-expo for mobile.

## Do
- Root: npm workspaces (`packages/*`, `pipeline`, `apps/*`), `tsconfig.base.json`, ESLint (typescript-eslint for shared/pipeline; eslint-config-expo for mobile), Prettier, `.gitignore`, `.env.example` (names only), CI workflow.
- `packages/shared`: vocab stubs (roast, process, kind, dataStatus), `CITIES`, `OPENFREEMAP_STYLE`; smoke test.
- `pipeline`: `tsx` CLI with `--city --dry-run --max-cafes --skip-llm` (node:util parseArgs), stage list stub; config YAMLs; args tests.
- `apps/mobile`: strip the template; Stack layout; placeholder map screen with top bar; theme tokens; MapLibre config plugin; jest smoke test.
- `firebase/`: rules (public read on cities/cityIndex/cafes, deny all writes, pipelineState closed), indexes, firebase.json.
- Docs: AGENTS.md, CLAUDE.md, DESIGN.md, UX-CONTRACT.md, README.md.

## Scope
In: everything above. Out: real data access, filters, sheets, pipeline stages (WP-01+).

## Acceptance criteria
1. `npm install` succeeds at the root.
2. `npm run typecheck`, `npm run lint`, `npm test` pass (≥1 test per workspace).
3. `npm run pipeline -- --dry-run --city boston` prints the plan and exits 0. An unknown city exits 2.
4. `npx expo config` lists the `@maplibre/maplibre-react-native` plugin; Android package `com.cflog.coffeelog`.
5. No secrets committed; `.env.example` lists every variable name from 02 § Integrations.

## Verify with
`npm run typecheck && npm run lint && npm test && npm run pipeline -- --dry-run --city boston`
