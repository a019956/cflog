# WP-06 — Pipeline: normalise + publish + report + weekly workflow  (owner: @backend · implemented by Claude)

## Goal
Glue the stages into `runCity`: discover → crawl → PDF text → change detection → store JSON → Gemini jobs → normalise → diff-publish to Firestore → report. Add the weekly GitHub Actions workflow.

## Context
ADR-003, ADR-007, ADR-008, ADR-013. Firestore: `cafes/{id}` (embedded beans ≤200, menu ≤150, < 900 KB), `cityIndex/{city}` (sharded above 900 KB), `cities/{city}`, `pipelineState/{city}`.

## Rules implemented
- Change detection: `pagesHash` over (url + content hash) of every fetched page. Unchanged + previously extracted → skip extraction, no café write (summary carried from the previous cityIndex).
- Café write only when the content hash changes (timestamps excluded).
- A bean missing from a successful extraction is kept once (`beanMiss`) and removed at 2. The previous café doc is read only in that case, or when the menu job was skipped (keep the previous menu).
- A skipped Gemini job (budget, error or no key) → state `pagesHash: ''`, so the café is retried next run.
- Vanished café: hidden on the first run, deleted after 4. Partial runs (`--max-cafes`) never hide.
- `PIPELINE_MAX_WRITES`: stop cleanly; unprocessed cafés keep their previous state and summary.
- State safety valve: if `pipelineState` > 900 KB, first-seen dates are dropped.
- Report: `pipeline/out/report-<date>[-city].md/.json`. Dry runs also write `cafes-<city>.json`.
- Exit 1 when > 50% of crawls with a website failed.

## Workflow
`.github/workflows/pipeline.yml`: Mondays 09:00 UTC plus manual dispatch (city, dry_run, max_cafes). Matrix per city with `max-parallel: 1`. Per-job budgets: `PIPELINE_MAX_WRITES` 6000 and `GEMINI_MAX_CALLS` 300 (repo variables override). Reports are uploaded as artifacts.
The remote-write tools can't write into `.github/workflows/` (protected path), so the file is staged at `.plan-code/pending/pipeline.yml` for Min to move.

## Verify with
`npm run typecheck && npm run lint && npm test` (pipeline: 72 tests, including a two-run end-to-end test with fake Overture, web and Gemini).
