# WP-04 — Pipeline: store-JSON + keyword extraction  (owner: @backend · implemented by Claude)

## Goal
Turn Shopify `/products.json` and WooCommerce Store API bodies into `RawBean[]`. Drop merch, gear, tea and subscriptions. Fill origin, process, roast, notes, varieties, decaf, blend, price and size with a deterministic keyword pass.

## Context
02 § Platform detection & store endpoints. The raw types (`RawBean`, `RawMenuItem`, `ExtractionResult`) are shared with the Gemini extractor (WP-05). The normaliser (WP-06) maps raw strings to vocabularies with `parseRoast` / `parseProcess`.

## Scope
In: `packages/shared/src/products.ts` (`isCoffeeProduct`), `pipeline/src/extract/{types,keywords,shopify,woocommerce,index}.ts`, fixtures, tests.

## Acceptance criteria
1. Coffee filter keeps beans (incl. "Filter Roast", "Cup of Excellence", "tea-like") and drops merch, gear, tea, subscriptions, concentrate and gift cards.
2. Shopify: smallest available bag variant gives the price and size; URL = `/products/<handle>`; de-duplicated across pages.
3. Woo: attributes (origin, process, roast, notes, variety, size) are used first; price from minor units; non-USD prices are ignored.
4. Keyword pass: labelled values win. Bare "natural"/"honey" in descriptions is not a process, though it counts in titles. Varieties include Pink Bourbon vs "bourbon barrel". Sizes convert to grams.
5. Fixture tests only.
