# WP-05 — Pipeline: Gemini extraction (beans + menus, PDF)  (owner: @backend · implemented by Claude)

## Goal
For sites without store JSON, and for all menus, send cleaned page text to Gemini's free tier and get beans and menu items back as JSON. Stay within the rate and call budgets.

## Context
ADR-002. Env: `GEMINI_API_KEY`, `GEMINI_MODEL` (default `gemini-flash-lite-latest`), `GEMINI_RPM` (10), `GEMINI_MAX_CALLS` (400). Priorities: (1) no store beans + coffee/shop pages → beans+menu in one call; (2) store beans + menu/PDF pages → menu only; (3) no store beans, home/menu pages only → beans+menu. PDF text via `unpdf`; image-only PDFs give no text, so no call.

## Scope
In: `pipeline/src/extract/{llm,plan,pdf}.ts`, `RawBean.flavorFamilies`, fixture `menu.pdf`, tests.

## Acceptance criteria
1. REST `generateContent` with `responseMimeType: application/json` + `responseJsonSchema`, temperature 0, `x-goog-api-key` header.
2. Throttle to RPM, back off on 429/5xx (honour `retryDelay`), throw `LlmBudgetExceeded` at the cap, and surface 4xx messages.
3. `sanitizeExtraction` coerces types, validates ISO countries and menu categories, and caps list sizes.
4. `planLlmJobs` priority order and modes as above.
5. Tests: mocked transport, virtual clock, real PDF fixture.

## Verify with
`npm run typecheck && npm run lint && npm test -w @cflog/pipeline`
