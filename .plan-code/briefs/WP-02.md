# WP-02 — Pipeline: discover (Overture + chains + overrides)  (owner: @backend · implemented by Claude)

## Goal
For each launch city, list candidate cafés/roasters from Overture Places. Filter by coffee category, confidence and operating status, drop large chains, de-duplicate, detect roasters, apply overrides, and write `pipeline/out/candidates-<city>.json`.

## Context
- ADR-001 (Overture), ADR-008 (overrides), ADR-014 (deny-list only; ≥5 locations flagged for review).
- Overture release 2026-09-23.0 replaced `categories` with `taxonomy {primary, hierarchy, alternates}` + `basic_category`, and added `operating_status`.
- Read with `@duckdb/node-api` from `s3://overturemaps-us-west-2/release/{release}/theme=places/type=place/*` using the `bbox` struct columns.

## Scope
In: `pipeline/src/{config.ts,args.ts,index.ts,discover/**}`, `pipeline/config/*.yaml`, `pipeline/test/**`. Out: crawl and later stages.

## Acceptance criteria
1. Config YAMLs load and validate, with clear `ConfigError`s.
2. The SQL selects places in the bbox whose primary category is in the configured list, or whose alternates include a configured alternate category.
3. Drops: no name, hidden, closed, low confidence, chain (name or brand; case- and punctuation-insensitive; prefix match), duplicate (same name within 50 m).
4. `kind`: a roaster category or a roaster name gives `roaster`, otherwise `cafe`. Overrides `patch.kind` can set `both`.
5. Website cleaned (no query/fragment, no social profiles); Instagram captured separately.
6. Multi-location names (≥ threshold across cities) printed for review.
7. Tests cover all of the above, including the real SQL against a local Parquet fixture (no network).
8. `--inspect-categories` prints the primary categories of coffee-sounding places, to verify the taxonomy ids against the live release.

## Verify with
`npm run typecheck && npm run lint && npm test -w @cflog/pipeline`
Live check (needs S3 access: Windows or GitHub Actions): `npm run pipeline -- --inspect-categories --city boston`, then `npm run pipeline -- --dry-run --city boston`.
